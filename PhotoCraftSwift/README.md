**Photato** is the native macOS image editor. It is an independent open-source fork/port of [PhotoCraft](https://github.com/storytold/photocraft), originally written in Rust by the **ArtCraft Team and PhotoCraft contributors**. Source is licensed **MIT OR Apache-2.0**; upstream notices are retained in [NOTICE](NOTICE) and [ATTRIBUTION](ATTRIBUTION.md).

A running **migration preview**, not a completed Photoshop replacement. The Rust source remains in `../photocraft-main`; the application and its editing engine here are Swift, using AppKit, SwiftUI and Apple imaging frameworks. No Rust library, embedded browser, JavaScript runtime or third-party package is linked into the app. The optional API serves a separate HTML/CSS/JavaScript demonstration to an external browser; all editing executes in Swift. Optional image generation uses Apple's Image Playground framework, including Private Cloud Compute on macOS 27+.

## Formats

- `.photato` (legacy `.pcswift` also readable): versioned native layered archives preserve editable content, metadata and binary raster tiles. This build reads versions1–42; newly added editable Render filters require version42. Older readers reject unsupported content instead of silently flattening it. Original Rust `.pcraft` has a bounded editable import path; see [import coverage and limits](docs/PCRAFT_IMPORT_REFERENCES.json).
- PNG/JPEG/TIFF import/export: ImageIO and explicit sRGB conversion; all eight EXIF orientations; resolution metadata; 16-bit PNG/TIFF export, JPEG flattened against white. HDR is retained in the float working document; the canvas is SDR and integer exports clamp extended values.
- PSD v1: **RGB/8/16/32 raster, solid-color fill, RGB Levels/Curves/Hue-Saturation/Color Balance/Threshold/Posterize, RGB8/16 Gradient Map, Gradient/Pattern Fill, group, clipping, path and mask interchange**. Supports raw/RLE/ZIP/ZIP-prediction import and ZIP-prediction export. Photoshop-saved fixtures qualify specific behaviors, not full parity. RGB/8 and RGB/16 fill references plus a 64-color RGB/16 matrix match exactly; float fills, feathered vector edges and broader group composition still have measured differences. Five of seven pinned original PSD corpus files import; two match at document depth and three differ. Other rich layers, alpha/spot channels, non-RGB editing and affine mask export remain pending. See [status and measured limits](docs/STATUS.md).
- PSB container support (step119, under qualification) uses the shared RGB8/16/32 codec, native Open/Save/Copy and APIs, including wide length fields and RLE rows. Current limits are512MiB input/output,32768 pixels per dimension and36million canvas pixels, with stricter API budgets. Nine pinned external PSD/PSB pairs match decoded samples/profiles/structure; one rich-content pair rejects explicitly. Live Photoshop and full large-file qualification remain open. See [PSB evidence](docs/PSB_REFERENCES.json).
- Multi-gigabyte PSB streaming, full PSD, complete original `.pcraft` fidelity, camera RAW and additional professional formats remain pending.
