Owned procedural PSDs with Normal raster layers. RGB8 and RGB16 use two full-canvas layers with an opacity ramp. The offset fixture uses three staggered layers with holes. No external artwork is included.

The .rgba files contain the decoded output of Photoshop 27.2 Save a Copy PNG, in row-major straight RGBA order. RGB16 stores words big-endian. Decoding and comparing the sampled channels excludes all PNG metadata and compression choices. provenance.json records both the original capture and the fixture digests.
