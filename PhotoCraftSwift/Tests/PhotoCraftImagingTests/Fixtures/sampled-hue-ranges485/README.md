# Sampled Hue/Saturation references

Four project-owned Photoshop 2026 PSDs record plain, additive, subtractive and achromatic color sampling through the native Properties panel. Exact literal source colors, file hashes, hue2 range bounds and display-color triples are in provenance.json. No Adobe implementation is included. The adjustment values are neutral: these files qualify metadata and control semantics, not every pixel transfer.
