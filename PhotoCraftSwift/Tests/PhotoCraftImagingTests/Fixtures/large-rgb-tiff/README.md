# RGB16 TIFF control

This file was generated from a synthetic 9,000 × 8,000 image. Four pixels carry unique RGB and alpha values, with hidden RGB at full transparency. All other words are zero. `source.json` records the authored samples and the raw reference hash. libtiff converted the raw reference with `tiffcp -L -c lzw:2 -r 31` to produce the included fixture.
