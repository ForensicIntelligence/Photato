# Original PhotoCraft decoder fixtures

The three `.pcraft` projects and 42 blob streams were generated by an independent Rust caller against the unchanged original PhotoCraft `crates/format` and related crates. They are procedural data owned by this project, available under MIT OR Apache-2.0. Rust is used only to generate fixtures, not by the Swift application.

`manifest.json` records deterministic blob inputs/hashes, 48 Zstandard CLI 1.5.7 cases and four Python-standard-library ZIP cases. The source caller, locked Cargo dependencies, generation script, input hashes and command logs are preserved in development step149. All compressed data is synthetic, without user documents.

BLAKE3 vectors use the first 32 bytes of each official unkeyed test vector, with input byte `i % 251`. Upstream commit `f55849f89cd85083c1c9daa2c5de20766f309c00`, https://github.com/BLAKE3-team/BLAKE3/tree/f55849f89cd85083c1c9daa2c5de20766f309c00/test_vectors . The upstream CC0 license is retained here. Native hashing follows the official CC0 reference algorithm. Zstandard decoding follows RFC8878 and the official format specification pinned in step149; the terminal FSE-weight rule was checked against ruzstd0.9.1 source. No external codec is linked into the application.
