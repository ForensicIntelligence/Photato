# Saved layer styles

Use Window > Styles to show the native preset panel. In Layer Style, choose New Style to save the private preview without committing it to the document. New Style in the panel saves the active layer's settings. The name dialog has Include Layer Effects and Include Layer Blending Options. The current initial choices are effects on and blending off; exact Photoshop factory defaults remain unverified.

Select a preset to apply it to the selected image layers. Command/Shift selects library entries without applying them; the context menu also provides Apply Style. The panel supports groups, rename, duplication, moving to groups and confirmed deletion. Saving or organizing presets does not change document pixels, dirty state or image Undo. Applied styles are independent of later library edits or deletion.

Effects and general blending can be captured separately. Effects-only application preserves target opacity, blend mode, Fill opacity and channel exclusions. Including blending captures those controls plus existing clipping-group and group pass-through settings. Pattern dependencies are embedded rather than looked up in the original document. Conflicting IDs receive new identities while existing document artwork stays intact. Applying uses one shared native transaction and Undo/Redo; portable Actions retain resources even when they were already installed at recording time, and remap conflicts during replay.

The library persists in the application's Styles.pclibrary file. Preparation validates before atomic replacement; failed, cancelled, stale or revoked preparation cannot publish. A corrupt saved library is preserved and not overwritten. The initial working bounds are 4,096 entries, 64 group levels, 64MP aggregate pattern resources and a 512MiB file. Existing effect and API document limits remain. These are implementation bounds, not Photoshop maximum claims. The internal format is not Adobe ASL. ASL Import/Export remain visibly unavailable pending implementation.

## Optional API

`style.library` accepts list, create, inspect, group.create, rename, move, duplicate, delete and apply. List needs the normal document revision. Other operations also require the current libraryRevision from state. Create accepts name, source layerID, optional style override, includesEffects/includesBlending and parentID. Apply takes nodeID and layerIDs. Structural operations use explicit node IDs and optional parent/before targets. Names and content retain Unicode; invalid IDs, stale revisions, busy/modal contexts, locks and malformed fields reject atomically.

Routine state carries metadata. Inspect returns full effect/blending descriptors, bounded to 2MiB, so routine image replies do not copy large PSD descriptors. The existing layer-style schemas now describe native pattern and gradient fills concretely. There are 262 typed commands; no matching preset-library route exists in the pinned Firefly v2 contract, and no undocumented Adobe endpoint was added. Internal library format 1, panel catalogue 4 and Actions 57 are separate from native document format 89. Complete older panel catalogues migrate strictly, preserving placements and adding hidden Styles.
