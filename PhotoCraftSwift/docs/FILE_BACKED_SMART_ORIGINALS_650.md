# File-backed Smart Object originals

19 November 2026 · Development checkpoint 650

Local placement now captures the original from one verified file descriptor. Files larger than 64 MiB are copied in 64 KiB chunks to private temporary storage. The retained bytes remain available after the original path changes. The reader checks the file identity before accepting the copy. When an extended attribute changes, the reader retries on the same file and accepts the retry only if the two copies agree.

Paged native, PSD and PSB reopens place layered originals above 256 MiB in the document's disk scratch budget. The native reader reuses one checked blob for layers that share the original. Archive version 96 marks the higher encoded size range. The local encoded ceiling is 512 MiB for PSD, PSB and chunked native documents. The 256 MiB budget for generated child output and the existing HTTP transfer budgets still apply. The saved Photoshop records continue to use the original `liFD` payload and source identifier.
