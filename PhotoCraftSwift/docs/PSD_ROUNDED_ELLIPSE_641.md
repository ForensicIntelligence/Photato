# Editable rounded rectangles and ellipses in Photoshop files

19 November 2026 · Development preview 641

Photato opens and saves individual, axis-aligned rounded rectangles and ellipses as editable shape layers in RGB8 and RGB16 PSD and PSB. The layer retains its own fill and stroke. The four corner radii of a rounded rectangle remain independently editable. Solid-color dashed and dotted strokes retain their cap, join, alignment, width and dash lengths when the lengths are relative to stroke width and the phase is zero. Native Save and the optional Photato API use the same writer. [Adobe rectangle controls](https://helpx.adobe.com/photoshop/desktop/draw-shapes-paths/create-shapes/draw-rectangles-with-the-rectangle-tool.html) · [Adobe file format specification](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/)

The origination descriptor distinguishes the rounded rectangle and ellipse from a square-corner rectangle. The decoder compares the archived cubic contour with the declared primitive and keeps the original contour and raster cache. At the maximum corner radius Photoshop can omit straight segments that have collapsed to a point. Native shapes at fractional positions use the compositor's bilinear sampler to project the raster cache to integer PSD layer bounds. The live outline still uses its fractional document coordinates.
