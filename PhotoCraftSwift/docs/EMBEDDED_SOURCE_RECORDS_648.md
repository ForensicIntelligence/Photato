# Keeping large embedded Photoshop sources once

19 November 2026 · Development checkpoint 648

Photoshop stores the originals for embedded Smart Objects in linked-file records. The reader now inspects those records as bounded views and keeps the editable originals. For a block larger than 64 MiB, the native document omits the redundant copy of that block. The writer sends each source and its small record header to the file output in order. A paged read counts the original bytes against its heap budget. A Photoshop open-parameters descriptor is limited independently of the embedded original that follows it.
