# Color and vibrance with Adjustment Brush

Photato's native Adjustment Brush now offers Color and vibrance in the first position of the 16-item picker observed in installed Photoshop 2026. Light, Clarity and dehaze, and Grain were not in that picker and have not been added to it. Legacy Vibrance remains readable through existing documents, API requests and Actions; it appears in the native picker when needed for an already selected or configured legacy layer.

A first stroke creates an editable modern adjustment and a black pixel mask. The observed brush creation values are Temperature 0, Tint 0, Vibrance 100 and Saturation 0. These were observed in the current Photoshop profile; they are not proven factory defaults. Ordinary modern adjustment creation remains neutral. Later painting and object targeting retain the current layer's settings, mask transform, density and feather. Add/Subtract, selection clipping, one Undo per committed stroke, preview cancellation and existing locked/disabled-mask guards use the shared native implementation.

The optional native API keeps adjustmentBrush.configure, adjustmentBrush.stroke, adjustmentBrush.object and adjustmentBrush.edit. The new kind is colorVibrance. Its settings object contains temperature, tint, vibrance and saturation, each finite and within -100...100. Partial edits retain omitted controls and the existing model seed. Unsupported useLegacy, preset and seed input fields reject rather than disappearing. State and capability schemas include the new type and expose the separate native picker order. The API and native workflow share the same request and engine; this does not establish equality with Adobe's transfer. No additional published Firefly route or unverified desktop descriptor is claimed.

Modern Color and vibrance brush recordings require portable Actions 61. Older Vibrance, Exposure, Color Lookup and ordinary modern adjustment recipes retain their existing feature minima. Modern layers use the existing native archive support from version 65; maximum native format 92 and 271 typed command identities are unchanged.

Two PSD references were saved from one owned analytic image in installed Photoshop through its native UI. Their PSD vibA descriptors explicitly contain useLegacy=false; the previous importer discarded that field and interpreted the record as legacy Vibrance. Import now distinguishes the modern settings, including the observed Default and Custom white-balance states, and rejects unrepresented fields and presets. Source descriptors and masks remain retained. Editable modern PSD/PSB output still rejects; keep the Photato original or explicitly export a flattened copy. No proprietary Adobe implementation or image asset was inspected or copied.

Current Source03 Debug passes 46 selected methods, including all 12 new methods, on 7,859 unchanged frozen inputs. Tests exercise RGB8/16/32 local masks, preview/cancel, selection, history, native archive, Actions replay/version guards, object targeting/cancellation, actual HTTP requests, strict schemas and legacy compatibility. Existing global maximum Actions assertions were advanced to 61; feature-specific minima and numerical assertions were retained. One old selected Lookup command-count assertion was corrected from its stale 267 to the actual preexisting 271.

The signed sandboxed Debug app also completed an actual native RGB8 workflow: owned PNG import, picker selection, stroke, one Undo/Redo, all four Properties edits, another dab, Save As a separate Photato file, close/reopen with matching controls and mask, then normal Quit. The first Save-panel Go To sequence was premature; it was recovered with separately observed transitions and exact folder/name checks. The original PNG was not changed. Native screenshots are retained in the conversation. Optimized ARM and translated Intel each pass the same 46 selected methods and all 12 new methods. The universal candidate passes static packaging checks and remains unlaunched/uninstalled.

Independent Photoshop output equality is not achieved. Across 2,359,296 RGB samples per owned fixture, the Vibrance-only case differs at 44,797 samples with a maximum difference of 36 byte levels. The four-control case differs at 37,102 samples with a maximum of 27. All differences lie inside the imported mask; outside-mask differences are zero. Source02's initial diagnostic labels used mask-local coordinates and were wrong; Source03 corrects that classification with the shared document-space sampler without changing total differences, fixtures or transfer. These failures remain required work, not a successful byte-equivalence claim or a cleanup waiver.

Full B08 and A04 remain open: exact modern and legacy transfers, Use Legacy switching, complete white-balance presets and sampling, factory settings/shortcuts, editable modern PSD/PSB output, full professional combinations, large/dense object-targeting limits, supported physical hardware/macOS versions, sustained 60 fps, full regression and all earlier failures. All 104 original scopes, 652 original command identities, 81 major memberships and seven scheduling passes remain. This is a development source checkpoint, not a software release; releases require manual approval.
