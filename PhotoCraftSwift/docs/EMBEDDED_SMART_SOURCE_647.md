# Saving large embedded Smart Objects

19 November 2026 · Development checkpoint 647

Photato used to generate a full raw preview when it converted a native Smart Object into an embedded PSB. Two translucent RGB files at 4,097 × 2,049 pixels each exceeded the 64 MiB embedded-source budget because of that preview. The same 16-bit and 32-bit fixtures reproduced the rejection in build 646 even when placed in a 512 × 256 parent. Baseline reproduction (local evidence)

The writer now tries a raw child preview first, then PackBits. If neither fits and the child is an eligible layered RGB document, the embedded PSB uses Photoshop's compatibility-off representation. It retains the editable layer, names, alpha and numerical samples. The parent still uses the selected Photoshop save settings, including its own merged preview. The bounded serializer checks exact raw preview capacity before rendering it and retries only the current writer's size overflow. Source formats that are already supported as embedded file bytes are copied through that existing path.
