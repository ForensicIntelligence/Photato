# Custom Filter presets

Filter > Other > Custom can load Photoshop ACF presets and existing Photato JSON presets. Save offers both formats. ACF is the default for whole-number settings; fractional Scale or Offset selects JSON and disables ACF so no values are silently rounded. Native preset I/O failures leave a ready filter preview usable.

ACF files contain exactly 54 bytes: 25 row-major signed big-endian 16-bit weights, Scale and Offset. Weights range from −999 to 999, Scale from 1 to 9999 and Offset from −9999 to 9999. Scale and Offset must be whole numbers for ACF. JSON preserves existing fractional settings and is bounded to 16 KiB. Invalid data is rejected before publication or filter commit.

The optional Photato API exposes `filter.custom.preset`. Supply `operation: "decode"`, `format: "acf"` or `"json"` and canonical base64 `data`; or `operation: "encode"`, `format` and `settings` containing the existing Custom Filter kernel/scale/offset schema. The authenticated request still requires a shared document and current revision. The response supplies base64 bytes, byte length, suggested filename, content type and a canonical `filter` for the existing `filter.apply` command. Conversion alone changes no document, history or file. Busy, stale and revoked requests retain the standard errors. Parameter/result schemas and capability metadata are published by the API. No Adobe route has been invented for this utility; broader Custom Filter descriptor compatibility remains open.
