19 November 2026 · Development checkpoint 649

File > Place Embedded and the shared replacement path now accept up to 256 MiB of encoded PSD, PSB or chunked native document data. The file reader chooses the budget from the source signature, and the saved object checks that its declared format agrees with the bytes. Other embedded file types keep the 64 MiB budget. Decode, document and scratch budgets still apply. Photoshop's linked-file records carry the original PSD or PSB bytes and their source identifier. [Adobe file format specification](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/)

A native parent with an original above 64 MiB requires archive version 95. The Photato transfer API now advertises and accepts explicit native versions 94 and 95. The source POST still accepts up to 64 MiB, and shared-document and file-download admission retain their 128 MiB budgets. Generated RGB children try raw, PackBits and compatibility-off options within 64 MiB before trying those same options with the larger budget. The Photoshop-compatible job paths share the file codec and keep their published request contract. [Automation API](AUTOMATION_API.md)
