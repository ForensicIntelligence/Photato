# Bound rotated Pattern Overlay viewports

Rotated and nonperiodic Pattern Overlay renders in bounded document viewports on canvases up to 300,000 × 300,000. The editor composites the visible document rectangle first and scales that result for display. The rectangular raster retains the canvas origin for pickers, linked pattern placement and panning. The same compositor supports the local PNG routes. [Photoshop zoom](https://helpx.adobe.com/photoshop/desktop/get-started/learn-the-basics/zoom-images.html) · [Photoshop navigation](https://helpx.adobe.com/photoshop/desktop/get-started/learn-the-basics/navigate-and-pan-images.html) · [Pattern Overlay](https://helpx.adobe.com/photoshop/desktop/create-manage-layers/apply-layer-effects/layer-style-effects-and-options-overview.html)

At actual size, overlapping panned views matched at 8-, 16-, and 32-bit depth. A 31° pattern at 56% matched the ordinary renderer at actual size, at fractional zoom and above the direct in-memory patch limit. The native canvas and all three local PNG viewport routes produced identical PNGs in the tested RGB8 composite, channel and proof views. Eighteen samples from the saved Adobe Photoshop PSD also matched.

The Photoshop-authored `reference-patterns.psd` supplied the eighteen independently sampled RGB values at actual size. The maximum-size rotated, fractional and paged controls were generated from an owned 4 × 4 tile. Each produced the same RGBA bytes in all three test configurations.

453 of 456 selected tests passed in Apple Silicon Debug, optimized Apple Silicon, and optimized Intel under Rosetta. The same three failures reproduced the build 689 assertions. Both signed macOS 14+ preview slices launched offscreen. Fit-to-window on very large nonperiodic canvases still uses full rendering. The bounded route has a source budget of 16,777,216 pixels and an output budget of 4,194,304 pixels.
