# Reduce wide oblique Pattern Overlays in bounded patches

Fit on Screen and the local PNG overview reduce supported wide oblique Pattern Overlays without retaining the full composite. Each document-coordinate patch is reduced in the same tile order and with the same premultiplied accumulation as a retained composite. RGB isolation or soft proof projects the source patch before it contributes to the overview. [Photoshop zoom](https://helpx.adobe.com/photoshop/desktop/get-started/learn-the-basics/zoom-images.html) · [Pattern Overlay](https://helpx.adobe.com/photoshop/desktop/create-manage-layers/apply-layer-effects/layer-style-effects-and-options-overview.html)

Fractional edges matched retained rendering at RGB8, RGB16 and RGB32 in the tested composite, channel and proof views. The proof test also preserved a sparse implicit backdrop across the maximum canvas. Authenticated composite, channel and proof PNGs matched their retained native controls. The separate AppKit probe fitted and proofed a fully covered 70,000 × 520 document on both architectures.

On a 300,000 × 300,000 canvas, the 4,161 × 4,101 oblique source region produced the same 301 × 297 Float32 RGBA image as build 691's retained renderer. Peak resident memory on optimized Apple Silicon was 338.0 MiB with retained samples and 72.6 MiB with paged reduction. The measured rendering times were 5.48 s and 5.52 s. The measurement covers a bounded output region and one owned document. In the separate AppKit probe, the 70,000 × 520 fit took 13.9 s and its proof took 24.0 s on Apple Silicon. Both native PNGs also matched across architectures.

458 of 461 selected tests passed in Apple Silicon Debug, optimized Apple Silicon and optimized Intel under Rosetta. The same three failures reproduced build 691's assertions. Both signed macOS 14+ preview slices launched offscreen. Large nonperiodic fits still evaluate source pixels and can take seconds or longer. End-to-end timing for a fully covered maximum-size oblique Fit remains open. The Photoshop 2026 document-count query timed out, leaving live zoom comparison open.
