# Channel drag and drop

19 November 2026 · Development preview 628

The Channels panel now lets a user drag an individual channel name onto **New Channel** to duplicate it, or onto another open image with matching dimensions to copy it there. Dropping on the trash deletes the dragged channel. Dropping beside a saved alpha or spot row, or beside another Multichannel plate, reorders that group. An insertion line marks the target edge. Adobe documents these entry points for Photoshop on desktop. [Duplicate and copy channels](https://helpx.adobe.com/photoshop/desktop/adjust-color/hdr-and-channel-manipulation/duplicate-split-and-merge-channels.html) · [Reorder and delete channels](https://helpx.adobe.com/photoshop/desktop/adjust-color/hdr-and-channel-manipulation/manage-channels-in-the-channels-panel.html)

`ChannelDragging.swift` gives each drag a process-local token and captures the document and session revision that supplied it. Incompatible, stale, closed, already-consumed and foreign transfers cannot commit. Copying into an open image uses the shared numerical channel duplication and one destination Undo. Saved-channel deletion and reordering use the Channels commands. Multichannel plates use the native ink commands. Dropping a process component on the trash uses immediate process deletion, which merges visible layers and discards hidden layers as part of the same undoable conversion to Multichannel.

`ChannelsPanel.swift`, `ModeChannelRows.swift` and `InkChannelRows.swift` provide the row sources and panel targets. `CanvasView.swift` recognizes the channel payload alongside the existing gradient drop. `AutomationChannels.swift` publishes `alphaChannels.nativeDrag`, which maps the gestures to the existing `channel.duplicate`, `channel.deleteProcess`, `channel.edit` and `ink.channel.manage` calls. These operations keep their existing schemas. [Photato API](AUTOMATION_API.md#drag-channels-preview-628)
