The comparison mapped those differences to the two regenerated `placed` identifiers in the outer and inner `SoLd` records. The open path had assigned each layer a new UUID. `PSDCodec` adopts an unused, valid placement UUID when opening a placed layer. `PSDSmartObjects` and `PSDSmartFilters` use the same saved spelling for the placement descriptor and filter cache. The writer checks that the saved UUID still belongs to the layer, so copies have distinct placement and cache identifiers. Cached linked layers also update their descriptor to reference the current shared source ID, including when transferred to a different document.
