Photato / Pantry · Planning snapshot · 9 October 2026 · Implementation paused

Everything currently outstanding on the path to Photoshop parity

This is a comprehensive inventory of known outstanding work after development step089, not a claim that all undocumented Photoshop behavior has been discovered. The application remains a native Swift/macOS14+ development preview. No implementation changes, new model downloads, purchases, publication or Photoshop document edits were made for this audit.

No defensible ETA exists for unconditional 100% parity. In particular, identical output for every possible document, proprietary/stochastic AI output, all Adobe services and arbitrary Photoshop plugins cannot be promised. Finite estimates below cover bounded implementation and qualification; research and external dependencies remain explicit.

How to read the ETA: time after that work package starts, with prerequisites ready, for one experienced native/macOS engineer assisted by AI. A week means five focused engineering days. These are planning judgments, not measured Codex wall-clock forecasts or deadlines from today. Tests and bounded workflow checks are included. Account/review waiting and additional translations are excluded.

Scale of the remaining programme: approximately 417–850 engineering-weeks before a 30–50% planning reserve. That is roughly 8–17 person-years, including 12–28 weeks of research allowances whose success is uncertain. This is effort, not a team calendar schedule, and it does not put an upper bound on the unknown items. Shared package estimates must not be added once per command.

Reference versions: the installed Photoshop application reports 27.2.0. Adobe’s current desktop release documentation describes 27.11 and additional 2026 features. The list includes those documented additions, with executable qualification still outstanding. The requested feature catalogue is discovery evidence, not an exhaustive acceptance specification. Beta, retired and platform-only features need an explicit disposition in AUD01.

Current evidence is encouraging but limited: 644 historical command rows are 153 partial/491 pending; some labels are stale (Quit is implemented). The separate 801-entry native menu inventory has 151 bound and573 unavailable leaf commands; there are 62 catalogued toolbar entries, 29 with native handlers. None of those counts measures percent parity. All 40 broad professional scenarios are still marked planned, even though some component behavior is implemented and tested.

Measured fidelity gaps already exist: Hue/Saturation references still differ at many pixels; vector-source alpha differs by up to 36/255 in the examined cases; RGB32 solid fill still has bit differences; Smooth/RGB16 gradient residuals remain. The report therefore estimates both missing functions and completion/verification of existing functions. See the retained status and qualification evidence.

Priority remains UI → menus → UX → major functions → subfunctions → minor functions. Core prerequisites may need to precede their corresponding UI. Dependency labels identify coordination; this is not yet a resource-loaded calendar schedule.
