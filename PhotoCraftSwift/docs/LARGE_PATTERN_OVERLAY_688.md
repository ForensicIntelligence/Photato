# Render Pattern Overlay on large canvases

Basic RGB Pattern Overlay can be edited and previewed on sparse canvases up to 300,000 × 300,000. Layer Style and the local API share the same validation and history transaction. A render patch keeps its absolute document coordinates, including the linked layer origin and fractional coverage. The compositor skips implicit tiles when the translated raster and surrounding layers can be proved uniform there. [Adobe layer styles](https://helpx.adobe.com/uk/photoshop/desktop/create-manage-layers/apply-layer-effects/layer-style-effects-and-options-overview.html) · [PSB dimensions](https://helpx.adobe.com/photoshop/desktop/save-and-export/export-files-to-different-formats/image-file-formats-supported-in-photoshop.html)

Across RGB8, RGB16 and RGB32, a 30 × 30 crop that crossed tile boundaries matched the small-canvas control byte for byte. The test covered linked and document-relative placement, partial layer coverage, a pixel mask, and a translucent backdrop. The largest PSB reopened through the native file-backed reader and preserved the style and all 3,600 crop bytes. A 6,000 × 2,000 PSB was byte-identical across the three builds. The loopback API applied and patched the overlay on a maximum-size document and transferred an editable 4,096 × 4,096 PSB.

The maximum-size RGB8 file used the existing Maximize Compatibility option to omit the merged image. Its white RLE placeholder occupied about 4.22 GB, so the test used the file-backed writer. The authenticated HTTP transfer still uses an in-memory response limit.

448 of 451 selected tests passed in Apple Silicon Debug, optimized Apple Silicon, and optimized Intel under Rosetta. Three failures repeated with the same assertions as build 687. Both signed macOS 14+ preview slices launched offscreen. Dense full-canvas output, mixed spatial effects and maximum-size HTTP PSB transfers remain open. Photoshop 2026 reported version 27.2.0.
