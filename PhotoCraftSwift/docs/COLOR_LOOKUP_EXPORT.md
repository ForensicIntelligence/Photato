# Export Color Lookup Tables

File > Export > Color Lookup Tables creates a CUBE table from a global RGB adjustment stack above Background. It samples the existing native compositor, retaining the document's RGB sample space, bit-depth transfer, adjustment order, opacity and supported blending. The original image, selection, layers, dirty state and Undo history are unchanged. Native export has Description and Grid Points controls and the standard macOS file chooser. The current default is 32 points.

The current range is 2–129 grid points and the output limit is 64 MiB. Hidden adjustments are ignored. Neutral or disabled pixel masks are supported. Spatial masks, pixel overlays, groups, clipping, Dissolve, dithering, active Grain and neighborhood adjustments reject with a reason because this path requires one global color function. Other formats, additional contexts, full Photoshop ranges/defaults and color-management/output fidelity remain open. This delivers the selected I05 quick win; the full production-export package remains open.

The optional Photato API uses `GET /v1/documents/{id}/color-lookup.cube`, requiring document transfers. Optional headers are `X-Photato-LUT-Grid-Points` (integer, default 32), `X-Photato-LUT-Description` (percent-encoded UTF-8, maximum 1024 bytes, no ASCII controls), and `X-Photato-Revision`. State `colorLookupExport` reports availability, dialog, operationID and busy status. Capability `colorLookup.stackExport` publishes the contract. `image.export.cancel` cancels the matching operationID; an incorrect ID returns 409 without interrupting another operation. Native and API use the same cancellable preparation and reject busy, stale, unsupported or revoked requests without returning an obsolete table. Existing loaded-table routes retain their contracts. There is no new Adobe v2 route or unqualified action descriptor.

Checkpoint 405 passes 80 identical ordered normal Release cases on Apple Silicon and translated Intel, including 12 new tests. Independent checks cover CUBE corners/order and every sampled compositor node at 8/16/32 bits. Both the development app and final optimized universal app saved an owned 181-byte inversion table, byte-identical between builds and independently verified against all eight literal corners. One Undo removed the original adjustment and restored the clean source. Both candidates quit normally. The universal package passes signature, minimum macOS 14 and ZIP extraction checks. Full current-suite, physical Intel/macOS 14+, dense capacity, physical 60 fps and Photoshop output qualification remain open.
