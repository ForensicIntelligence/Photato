# Improve RGB8 shape opacity and legacy pattern placement

The RGB8 Normal shape compositor rounds the product of layer opacity and per-pixel coverage to an eight-bit value. It also rounds accumulated alpha at each layer and calculates straight color from the combined weights. The implementation covers unmasked, unstyled shape rasters on the pixel grid. The opaque-source and empty-backdrop paths are algebraically equivalent.

The Photoshop-authored ellipse file was previously rejected because its Float32 Bézier handles could differ from the analytic ellipse by more than one PSD path step. Matching allows two steps and keeps the original contours. The older pattern records are editable as shapes. Linked phase is relative to the stored Photoshop reference point and unscaled sampling rounds the absolute phase. The descriptor retains the fractional control. [Layer opacity](https://helpx.adobe.com/photoshop/desktop/create-manage-layers/apply-layer-effects/set-layer-opacity-and-blending-modes.html) · [Photoshop file format](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/)

The original Photoshop stroke fixture’s regenerated preview dropped from 331 to 90 differing RGB bytes. The three translucent ellipses match every merged alpha byte and have 69 differing RGB bytes. The largest residual is one level in both files. Both original legacy pattern files keep their shape descriptors, layer caches, embedded tiles and merged planes byte for byte. After repeat-preserving edits, all 9,309 opaque interior pixels matched in each of four unscaled pattern cases and in the 50% case. [Authored opacity fixture](https://github.com/psd-tools/psd-tools/blob/6a827c19543106cd83a50fd830b07312df950531/tests/psd_files/blend-modes/normal.psd) · [Authored anchor fixture](https://github.com/psd-tools/psd-tools/blob/6a827c19543106cd83a50fd830b07312df950531/tests/psd_files/layers/pattern-fill-anchor.psd) · [Authored scale fixture](https://github.com/psd-tools/psd-tools/blob/6a827c19543106cd83a50fd830b07312df950531/tests/psd_files/layers/pattern-fill-scale.psd)

All 310 selected tests passed in Apple Silicon Debug, optimized Apple Silicon, and optimized Intel under Rosetta. Both slices of the signed macOS 14+ preview launched offscreen. The same authored opacity sample matched in a 15 × 15 viewport on a 300,000 × 300,000 canvas. Twelve prior vector exports, thirteen prior shape outputs and three canvas-cutout outputs also retained exact bytes. The authenticated file transfer test checks the new capabilities and the shared native save path.

Scaled pattern repaint at 200%, 56%, and 25% still differs. Independent sampling matched the 200% fixture with a half-pixel coordinate shift and the 25% fixture with two rounded 2 × 2 reductions. Masked, styled, transformed and other depth or blend cases have separate acceptance requirements. Reopening in a live Photoshop 2026 session remains unverified.
