## 2026-11-17 — Start the first Brush frame sooner

The measurements from step 532 found a pre-render delay at the start of ordinary Brush strokes. Paint input first queues a main-actor pacing task, which calls the renderer, which in turn queues its main-actor publication task. The Apple guidance treats immediate in-context feedback as part of direct interaction. Adobe documents the separate effects of smoothing, spacing and brush complexity. A disposable 1208 × 1208 document in the installed Photoshop 2026 showed 10% smoothing after pressing B. The automated drag produced an initial mark only. Command-Z removed it, and the test document and Photoshop session were closed. This establishes the observed control and Undo behavior for that mark. Physical cadence, continuous drag and output bytes remain outside that check. [Apple feedback guidance](https://developer.apple.com/design/human-interface-guidelines/feedback) · [Adobe painting performance](https://helpx.adobe.com/photoshop/desktop/apply-painting-techniques/brushes-presets/optimize-painting-and-cloning-using-brush-settings.html).

BrushEditing.swift now captures the first ordinary Brush input during the event on a ready canvas. The existing background render then produces the pixels. If more samples arrive, the same paced task waits for that render and prepares the latest batch, including every sample. A loading canvas, masks and other paint tools use their established scheduling. CanvasFrameDiagnosticsTests.swift checks that the first preparation is recorded before input returns, that a ten-sample burst creates one follow-up frame, and that the final composite matches the complete brush command. AutomationBrushes.swift records the desktop behavior in capability metadata. Both APIs retain their current document operations and brush inputs. The candidate bundle version is 533.

Factory Brush settings need a separate correction. EditorStore.swift starts with the default Brush, and BrushSmoothing in BrushSettings.swift starts at 0%. The installed Photoshop control and Adobe's documentation put the ordinary round Brush default at 10%. A future change needs to distinguish native factory settings from explicit or omitted values in existing presets, Actions and automation requests.
