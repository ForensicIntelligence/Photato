## 2026-11-18 — Use the source tone curves for 32-bit RGB and Gray

Promoting an 8-bit or 16-bit RGB or grayscale document to 32 bits now uses the supported tone curves from its current ICC profile. The shared Swift path promotes integer samples through their ICC transfer curves. It uses a 15-bit working domain for nonlinear curves and stores a linearized version of the source profile. Sampled curves use a 4,097-point Float32 table. Power and the tested parametric curve use the measured direct or interpolated path. Explicit different destination profiles, other intents, and unsupported curves retain the existing ColorSync path.

The change is in `Sources/PhotoCraftCore/SDRToHDRTransfer.swift`, `DocumentMode.swift`, `NativeModeRaster.swift`, and `ICCProfile.swift`. It applies through Image > Mode > 32 Bits/Channel, the existing Photato conversion command, and the existing conversion step used by the Adobe-compatible action adapter. The capability is described in `Sources/PhotoCraft/AutomationDocumentMode.swift`.

The installed Adobe Photoshop 2026 27.2.0 application converted procedural ramps through the documented bit-depth operation. An independent reader compared the complete raw merged planes with the numerical planes in Photato. The first AppleScript attempts failed with file-reference and script-file errors. The succeeding inline script opened and closed only the owned fixtures. The repository includes five original ICC test fixtures, complete numerical plane hashes and a description of how the tests reconstruct the inputs. [Adobe bit-depth reference](https://helpx.adobe.com/photoshop/desktop/adjust-color/color-modes/bit-depth-in-photoshop.html).
