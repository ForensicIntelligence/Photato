# 505 — Edit a reference image

8 November 2026 in Vancouver; final validation receipts are dated 9 November UTC. AI05, major stillneeded pass. Build 505, Source01.

Photato can now explicitly ask Apple's image service to edit a reference image. The existing reference workflow supplied visual inspiration, with no way to request this different behavior. The new Use image as popup offers Inspiration and Image to edit. Inspiration remains the default, including its previous metadata encoding and system options. Editing requires a chosen image and an eligible Apple Silicon Mac running macOS 27 or later. Unavailable choices are disabled in the native menu and checked again when an action runs. An unsupported edit request is rejected without changing its meaning.

The implementation uses Apple's public ImagePlaygroundOptions.creationStrategy.editExisting. It captures the requested mode and orientation-corrected reference dimensions before work starts. Editing uses that reference's aspect ratio for the system size hint; inspiration and background generation retain the document-size policy. The accepted result goes through the existing original-storage, prepared-layer and single-Undo transaction. The reference file and original layers remain unchanged. A later draft edit cannot relabel a running request or its result.

The optional Photato API accepts referenceUse on image preparation, reports the captured mode and platform support, and includes draft-mode changes in its revision checks. Editing requires explicit reference bytes. Background preparation rejects this parameter. Native approval, permissions, current-window and lifecycle checks still apply; preparation does not start a model. No corresponding interactive lifecycle is defined in the pinned Photoshop v2 contract, so no Adobe route was added.

Version-1 reference metadata gains an optional requestedUse field. Default inspiration omits it, preserving the old encoding. It records the initial request, not an attestation of the provider's final input: the system interface can change settings or replace the image. Original reference bytes are not embedded in the generated result.
