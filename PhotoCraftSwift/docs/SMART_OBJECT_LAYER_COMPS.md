## Current implementation — checkpoint337

A placed native document with comps carries a derived choice catalogue and an independent selected UUID for each instance. Properties shows Layer Comp with Last Document State plus the source's named comps. Ordinary duplicates share original data/sourceID while retaining independent choices. Older native placed sources can load their choices explicitly. Nil means the source composition as saved in its retained bytes; choosing a comp does not change those bytes.

Selection prepares the source variation off the main thread, color-converts its cache with the existing engine, and commits one native Undo transaction. All parent transform/mask/style/Smart Filter/warp/projection fields remain unchanged. Source replacements rebuild every affected instance using its retained comp and stack mode. Deleted selected comps reject the update atomically; choose Last Document State before replacing a source that no longer has those comps. Source conversion from selected parent layers does not copy an unrelated parent comp library into the cropped child document.

SmartObject.layerComps stores bounded source choice IDs/names and selectedID. Render identity includes the selection; shared source validation ignores this per-instance state. Catalogue names/IDs are limited to2048 entries and4MiB metadata. Existing source64MiB, decoding256MiB, format/rendering/API limits still apply. Native80 retains choices and per-instance selection; old plain objects and native79 document comps retain their earlier feature versions. Direct PSD/PSB writes reject these unsupported descriptors instead of silently losing them.

## Linked originals and API

An already-owned source can be switched offline. Reopened linked native files retain their choice/cache but omit original bytes. Switching then requires the existing file grant, reads only that approved original, validates its fingerprint and rejects stale data. The API requires approval of that file for its current session. No URL fetch, filesystem discovery or implicit authorization is introduced.

`smartObject.layerComp` accepts layerID and compID (UUID or null) on the existing authenticated/current-revision command route. It uses the native selection preparation and history. Layer state exposes catalogue/selectedID and capability/parameter schemas. Native file downloads with these records require X-Photato-Archive-Version:80. Malformed requests reject400, semantic invalid states422, missing layers404, stale/busy/cancelled work409 and unauthorized original reads403. Source/share/session/file-authorization changes invalidate work; confirmed-live worker cancellation/revocation passes in Source02. The catalogue has213 typed commands. No dedicated Adobe endpoint is invented; execute-actions comp descriptors remain unsupported.
