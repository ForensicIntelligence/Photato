# Blur, Sharpen and Smudge blend modes

Development457 adds Normal, Darken, Lighten, Hue, Saturation, Color and Luminosity to the native focus-tool options. The mode is captured with the brush and follows the same full/incremental preparation, previews, targets, selection, opacity, cancellation, Undo and Actions path. The selected workflow passes focused tests and native checks; this is not full B04 or Photoshop output parity.

The shared processing engine computes its normal neighborhood/pickup result, blends that processed color with the original target, and applies the captured stroke opacity and selection. The effect alpha is retained; a transparency-locked target keeps its original alpha. Hidden RGB cannot tint newly exposed pixels. Scalar-mask Hue/Saturation/Color retain the target gray, while Luminosity uses processed gray. Float32 follows the existing native linear blending convention. Normal follows its original arithmetic path. The current neighborhood and Smudge pickup kernels are unchanged. Per-dab interaction, repeated strokes, profiles and exact Photoshop numerics are unqualified.

## Native and API

Each tool retains its own Mode selection within the current session. Native Mode changes advance the API revision without document history; selecting the unchanged value retains the revision. Existing retouch.stroke accepts brush.mode using the title-case names above. It captures explicit overrides without changing native defaults. Unsupported focus modes reject before publication; Dodge/Burn/Sponge retain their Normal-only contract. retouchTools.<tool>.brush.mode exposes the native defaults. Discovery and a conditional command parameter schema expose the seven supported choices. No new command identity or Adobe route is added.

```json
{"command":"retouch.stroke","revision":"<current revision>","parameters":{"tool":"blur","points":[{"x":24,"y":16}],"brush":{"mode":"Darken","size":12},"focus":{"strength":0.5}}}
```

Non-Normal focus Action recipes require version55 so older readers reject them explicitly. Ordinary retouch recipes retain version21; native documents remain at maximum88. Existing selection/target/body/working-set limits remain. No new modifier action or global shortcut is introduced; existing Smudge Option Finger Painting and cursor policies remain.
