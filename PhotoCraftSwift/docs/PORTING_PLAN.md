## Architecture

- **PhotoCraftCore**: geometry, runtime precision, sparse copy-on-write float tiles, straight-alpha blend math, document/layers/masks/selections, typed commands, bounded transactional history, versioned native archive. Pure Swift value types independent of UI.
- **PhotoCraftImaging**: Core Graphics/ColorSync profiles, ImageIO import/export, CoreText rasterization, native Swift reference filters. CPU compositor remains the correctness reference. Follow with tiled Metal acceleration once pixel oracles are established.
- **PhotoCraftAI**: runtime capability and execution-location checks; explicit Foundation Models SystemLanguageModel for local text; Image Playground with Apple illustration/animation/sketch styles, local on macOS 26 and using **Private Cloud Compute on macOS 27+**. Photo-realistic inpainting/outpainting needs a separately evaluated on-device image backend, proposed in Gate B. macOS 14 editing runs without AI. Image generation is user-initiated and its processing location is disclosed; local prompt refinement has no cloud fallback.
- **PhotoCraft**: AppKit document lifecycle, native menus/shortcuts/dialogs, SwiftUI inspector/layers/history and AppKit tablet-aware canvas. Commands own document mutation. NSDocument owns safe writes and unsaved-work prompts.
- **Tests**: analytic pixel cases, Rust-derived differential blend fixtures, malformed input, archive round trips, history transactions, generated image I/O, UI snapshots and workflow smoke checks. Each module is tested before integrating subsequent modules.
