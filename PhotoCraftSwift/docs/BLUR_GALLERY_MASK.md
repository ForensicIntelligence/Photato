# Blur Gallery masks

Select Filter > Blur Gallery and enable **Save Mask to Channels** before OK. Photato saves a grayscale alpha channel named **Blur Mask**, alongside the filter edit, in one transaction. Existing names use **Blur Mask 2**, **Blur Mask 3**, and so on. The channel starts hidden and RGB remains the editing target. Undo/Redo includes both the pixels and channel; Cancel creates neither. The option starts off when the workspace opens.

Mask preview and saved output use the same numeric coverage. Black marks sharp or out-of-source areas; white marks maximum configured blur. A uniform positive Field Blur produces full white, confirmed against an owned Photoshop five-pixel reference. Other tools use the current Gallery geometry and normalization; exact Photoshop spatial, selection, combined-tool and subpixel masks remain unqualified. Mask failures disable mask output without blocking an otherwise valid pixel filter.

The optional API command `filter.blurGallery.apply` takes `layerID`, `gallery` settings, optional `saveMaskToChannels` (default false) and optional existing `filterID` for Smart Filter re-editing. It shares the native prepared transaction, protection, history and cancellation/revocation guards. Re-editing retains the existing filter's opacity and blend mode.
