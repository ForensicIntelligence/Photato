# Multichannel channel order

19 November 2026 · Development preview 629

The Channels panel can now place a saved selection above or between printing plates in a Multichannel document. Drag a row or use its Move Up and Move Down commands. The same order is used for the native document and for PSD and PSB. Printing plates preview in their new relative order. [Adobe Channels documentation](https://helpx.adobe.com/photoshop/desktop/adjust-color/hdr-and-channel-manipulation/manage-channels-in-the-channels-panel.html) · [Adobe file format specification](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/)

The Swift document model stores the combined order only when the format needs it. Plates-first documents continue to use their original archive requirements. The usual group-relative operations keep the slots occupied by that group in an interleaved document, and deleting a row removes its slot. The PSD and PSB importer reads file order, including names, display kinds and retained channel identifiers. The exporter pairs that same order with the unchanged native samples through dense and paged row writers. Quick Mask keeps its separate temporary state and is emitted last.

`channel.edit` adds `action: "moveMultichannel"`, with `target` set to a saved channel or printing plate UUID and `index` set to its final zero-based row. `selectionChannels.multichannelOrder` returns the order. The native archive version for an interleaved document is 94. Photoshop v2 has no published channel-reorder endpoint. [Photato API](AUTOMATION_API.md#multichannel-row-order-checkpoint-629)
