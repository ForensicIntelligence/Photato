# Source checkpoint 556

Native Swift 0.3.0, build 556, 18 November 2026. Brush can paint Behind existing pixels or Clear their alpha. Pencil also supports Clear. The two modes appear in the paint tool's Mode picker. They are available on unlocked 8- and 16-bit pixel layers in RGB, Grayscale, CMYK and Lab. With Brush selected and the canvas focused, hold the grave-accent key for temporary Clear. A stroke keeps the mode it captured at mouse-down. [Adobe blend-mode descriptions](https://helpx.adobe.com/photoshop/desktop/repair-retouch/adjust-light-tone/blending-mode-descriptions.html) · [Adobe macOS shortcuts](https://helpx.adobe.com/content/dam/help/en/photoshop/using/default-keyboard-shortcuts/photoshop-keyboard-shortcuts.pdf).

Behind preserves opaque pixels and deposits new color underneath partial or empty alpha. Clear attenuates destination alpha using the stroke and selection coverage. It preserves color when alpha remains positive and writes transparent black when clearing a pixel fully. Independent pixel arithmetic and retained/full-render checks cover partial and opaque destinations, soft selections, and transparent foreground color for Clear. Native archives retain the tested 8- and 16-bit alpha samples across the four supported document modes.

The existing Photato brush settings expose paintMode through brush.configure, paint.stroke and paint.tool. Presets that retain the mode use native format version 4, and recorded raster Brush and Pencil steps use Action version 65. Native and HTTP outputs match. The tests cover Undo and Action replay, plus atomic rejection of locked destinations and Pencil Behind.
