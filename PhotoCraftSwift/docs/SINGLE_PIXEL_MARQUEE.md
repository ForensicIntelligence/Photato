# Single Row and Single Column Marquee

The two tools in the Marquee flyout create one full-width row or one full-height column. Click or drag to place the line; the outline follows the pointer, and release commits one selection history entry. Shift adds, Option subtracts, and both intersect. The combination mode and feather value are captured when the gesture starts. Escape, a tool change or loss of canvas focus discards the draft. Anti-alias is disabled for these straight pixel edges. The tools have no assigned shortcut; Shift-M cycles the rectangular and elliptical tools.

The optional Photato API uses `selection.shape` with `shape: {"row": 20}` or `shape: {"column": 10}`. Indices are zero-based integers within the current document. Existing mode/feather/busy/revision and Undo/Redo contracts apply. The native/API paths use shared canvas geometry and native selection commands. No dedicated Adobe v2 route is invented.

Checkpoint404 qualifies focused development tests, including both tools with all16modifier combinations, cancellation, native/API history, invalid/stale/busy requests and logical300,000-by-300,000 sparse persistence. This is not a claim of dense capacity or complete Photoshop selection parity. The first Debug build crashed in a Swift compiler optimization pass; the development retry disables that pass. Production Xcode/Release settings are unchanged; normal optimized universal qualification remains for a stable milestone.

Adobe's [marquee guide](https://helpx.adobe.com/photoshop/desktop/make-selections/get-started-selections/make-selections-with-marquee-tools.html) supplies behavioral guidance. Exact feather, snapping, outside-canvas gestures, factory preferences, pointer artwork, supported physical platforms and the remaining S01scope are open.
