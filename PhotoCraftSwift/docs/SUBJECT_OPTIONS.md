# Select Subject in selection tool options

The Object Selection and Quick Selection Options bar includes **Select Subject**, next to **Select and Mask**. It calls the same native foreground-selection engine as Select > Subject and the Properties quick action.

The button captures the Options bar’s **Sample All Layers** value when clicked. Off samples the active pixel layer, including its placement and mask; on samples the visible composite. Both replace the selection and leave source pixels, layer properties and the Properties/Menu sampling preference unchanged. The edit has one Undo. The selection-mode picker continues to control subsequent object/brush gestures.

Detection uses Apple’s on-device Vision foreground-instance model on macOS14+. The current engine requires an active raster layer, a composite image editing context, at most8,388,608canvas pixels and at most6000pixels per side. Locked pixel layers can be sampled. The new regression qualifies ordinary RGB16; other document modes and the complete inference context matrix remain unqualified. Detection is disabled during an edit/draft, AI task or active selection stroke. Runtime model failures and absent subjects remain explicit errors. These model and capacity limits are outstanding functionality gaps; this control does not close them or establish Adobe model equivalence.

The existing `selection.subject` API reproduces this action with an explicit active `layerID`, `sampleAllLayers` boolean and `mode: "replace"`. API defaults remain false/replace rather than inheriting tool settings. `selectionTools.canSelectSubject` exposes current native button availability. `selectionTools.subjectSelection` capability metadata maps its source fields and limits. The actual capability is under `capabilities.selectionTools.subjectSelection`; no new operation or Adobe endpoint is introduced. Existing remove-background Adobe jobs retain their separate published document/job contract.

No shortcut, factory menu or canvas modifier action changes. This is an ordinary button with no modifier alternate. Object/Quick gesture modes and their captured cursor policy remain unchanged.
