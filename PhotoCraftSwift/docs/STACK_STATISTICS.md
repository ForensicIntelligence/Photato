# Statistical image stacks

Build 417 corrects five existing stack operators against Adobe’s published definitions. The same Swift engine serves File > Scripts > Statistics, Smart Object Stack Mode, the Photato API and the supported Adobe action-job descriptors. No new menu item, operation or file format is introduced.

Variance now uses the sample denominator n−1; standard deviation is its square root. Skewness retains its signed standardized third moment. Kurtosis returns the raw standardized fourth moment, without dividing by 10 or clamping. Entropy counts equal stored finite channel values and returns Shannon information without dividing by log2(n) or collapsing values into 256 bins. Entropy counts are summed in sorted order to keep dictionary iteration from changing floating-point results. Intermediate moments use Double; results use native Float32.

For example, values 0, 0.5, 1 have variance 0.25 and entropy log2(3), approximately 1.585. Maximum, minimum, mean, median, range and summation retain their previous implementation. Empty/single-sample and constant standardized-moment estimates use an explicit finite-zero policy. That edge policy, exact Photoshop histogram/binning, rounding, precision, output scaling and displayed pixels remain unqualified. RGB32 can retain signed and above-one values; existing 8/16-bit output clipping/encoding still applies and has not been declared equivalent to Photoshop.

The reference is [Adobe’s image-stack rendering definitions](https://helpx.adobe.com/photoshop/desktop/create-manage-layers/create-layer-compositions/image-stack-rendering-modes.html), updated 6 October 2026, read 5 November 2026 UTC. The licensed Rust fixture remains unchanged as historical evidence. Its differential regression now covers the six operators whose mathematics still matches. A Rust comparison is not a Photoshop acceptance test.

Four new regression methods use 14 owned rational/80-digit Decimal vectors and 70 exact Float32 words, plus independently expected native RGB32 rendered words, native/API document and saved-byte equality, Undo/Redo, and all five corrected modes through both action-job routes. The job fixture requests TIFF, since the existing PNG encoder explicitly rejects RGB32 retention. The independent checker imports no Photato or Rust implementation. [Checkpoint 417](STACK_STATISTICS_417.json) records exact attempts and qualification; the first new job fixture’s PNG request is retained as a failed attempt.

Focused Debug qualification passes 41 cases. Normal ARM and translated Intel each pass 157 of 159 tests, including all eight new tests from 415–417. The same two pre-existing linked-preview and master-palette failures remain open. Both architectures match all 70 independent Float32 expectations. The isolated universal package passes macOS 14, signature and ZIP checks; it has not been launched. Full RAW02, including HDR merging, photomerge/align/blend/stack interoperability, Photoshop reference pixels, physical platforms, maximum documents and performance remains open. Native archive 86, Actions 47 and 246 typed API operations are unchanged.
