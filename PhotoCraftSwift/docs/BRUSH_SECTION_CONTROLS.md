# Brush setting group controls

Checkpoint413 adds enable checkboxes beside eleven existing Brush Settings groups. The checkbox on the left enables the group; Lock on the right preserves its settings when selecting another preset. Group controls remain available inside each section. Tip Shape, Smoothing and Symmetry retain their existing controls without a new enable flag.

The booleans are the existing `settings.shape.enabled`, `scattering.enabled`, `texture.enabled`, `dual.enabled`, `colorDynamics.enabled`, `transfer.enabled`, `pose.enabled`, `noise`, `wetEdges`, `buildUp` and `protectTexture` fields. `brush.configure` patches the same fields under `brush.settings`; existing brush state publishes them. `capabilities.brushes.sectionToggles` documents the mapping (the underlying `BrushAPI.capabilities` dictionary). This presentation change adds no API operation, request parameter or serialization version. Native controls reject active-stroke/geometry-busy changes; API busy/stale validation is unchanged. Tool settings create no document Undo entry; the next stroke captures them through the existing transaction.
