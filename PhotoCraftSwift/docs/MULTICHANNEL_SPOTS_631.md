# Spot inks in Multichannel Photoshop files

19 November 2026 · Development preview 631

Photato keeps saved spots when **Image > Mode > Multichannel** or **Delete Channels** removes the component image. The Multichannel PSD and PSB writer already emitted each spot's density in Photoshop's reversed gray convention. Its display record nevertheless identified the spot as an ordinary saved mask. Opening the written file dropped the spot swatch and Solidity and treated the ink sample as selection coverage.

`PSDInkChannels.swift` now uses the same display record as ordinary Photoshop files. `PSDAuxiliaryChannels.swift` chooses spot kind 2 and uses the ink's current swatch and Solidity. It preserves the exact retained Photoshop swatch bytes while they still represent the current ink. Channels with edited swatches or Solidity get a new display record. PSD and PSB write channel names, identifiers, order and samples through the existing paths. Native archives continue to retain the original spot channel, and a reopened Photoshop file exposes it as a printing plate.

Photato's authenticated capability catalogue documents the behavior under `inkModes.photoshopSpotOutput`. Both standard Photato file downloads and the desktop use the same writer. The existing conversion and process-deletion commands retain their schemas. The published Firefly v2 API has no dedicated spot-preservation operation.
