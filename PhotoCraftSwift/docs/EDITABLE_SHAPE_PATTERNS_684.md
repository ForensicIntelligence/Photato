# Keep patterns and straight lines editable in PSD and PSB

The shape generator reads and writes embedded pattern references in a fill or stroke. Shape descriptors store pattern phase in document coordinates. Photato converts linked phase into shape-local coordinates so the pattern follows a move. An unlinked pattern keeps its document origin, and a moved imported shape rerenders it instead of moving the old cache. Editable straight lines use the stored endpoints and thickness and verify the original vector contour.

The previous codec rejected the unmodified fixture. The new codec opens the whole document. The patterned polygon supplied 1,048 interior samples for comparing candidate phase origins. The document origin gave the closest fit at the declared 56% scale. A linked patterned stroke also favored the document origin over the cache and contour origins in two fitted rows. [Photoshop-authored fixture](https://github.com/psd-tools/psd-tools/blob/6a827c19543106cd83a50fd830b07312df950531/tests/psd_files/stroke.psd)

The original Photoshop fixture opens with all five shape layers editable. Both resaves preserve the six layer caches, live shape descriptors and both embedded pattern records byte for byte. An independent reader verified an edited polygon phase, a rounded rectangle’s 85% stroke scale and a diagonal line’s 4.5 px weight. The line kept its endpoints. Both edited files matched byte for byte across all three builds.

All 302 selected tests passed in Apple Silicon Debug, optimized Apple Silicon, and optimized Intel under Rosetta. Both slices of the signed macOS 14+ preview launched offscreen. An owned RGB16 fixture preserved its editable fill and stroke, original tile and composite bytes in both containers. Twelve prior whole-layer vector exports, thirteen earlier shape outputs and three canvas-cutout exports remained identical. The file transfer regression edits pattern and gradient shapes using the authenticated API and compares both output formats with the native encoder.

An independent numerical comparison reproduced four opaque-background stroke references with 100% layer opacity. In the original multi-layer file, rounding effective layer alpha to eight bits before blending reduced the remaining channel differences to 90. This is a diagnostic of the cached composites.

The regenerated merged preview differs in 331 color-channel bytes across 224 antialiased pixels, with a maximum difference of 1 in RGB and exact alpha. The 56% polygon pattern sample supports a document-origin phase. Its scaled sampling still differs. The 60° gradient diagnostic did not establish a universal half-pixel placement correction. Arrowheads and live Photoshop 2026 reopen and repaint checks remain open.
