# Eyedropper sampling

Choose Eyedropper using the existing toolbar/shortcut. Sample Size offers Point Sample and 3, 5, 11, 31, 51 or 101 square averages. Sample offers Current Layer, Current & Below, All Layers, All Layers no Adjustments, and Current & Below no Adjustments. Drag to update foreground; Option at press captures background. The ring shows the new colour above the captured colour, with a gray surround. Its native checkbox toggles visibility. Escape restores the initial colour pair when no other palette change intervened; focus/tool changes cancel pending samples. Shift Color Sampler points remain unavailable.

Settings are shared between controller documents and saved for production launches. Closing/detaching a document gives it an independent copy. The actual production startup factory and convenience constructor both load saved settings; validation sessions use memory only. Sampling and settings do not change document pixels, dirty state or Undo history.

The optional `color.sample` API uses the same native engine. `configure` patches size/source/showRing with the existing preference-write permission. `sample` requires x/y and defaults to read-only target none; foreground/background explicitly update the shared active paint context. Optional source/size/layer overrides do not replace settings. Replies expose RGBA, average coverage, clipped document region, visited/contributing counts and current revision. Channel/mask/nonRGB targets use the displayed preview with the document's semantic depth; explicit layer-source overrides reject. Busy, cancelled, stale and revoked requests do not publish.

Sampling visits at most101x101 pixels and uses regional layer composition rather than a full-canvas multilayer image. Integer documents currently average encoded RGB, Float32 documents linear RGB, weighted by visible alpha. Results are opaque colours, with coverage reported separately. These are candidate semantics: precise Photoshop zoom/footprint, masks/opacity/group/adjustment interpretation, alpha/CMM/profile/HDR rounding and factory defaults remain unqualified. The older public Adobe-employee reference describes zoom-dependent sampling and shared size with other tools; installed2026 comparison is still required. No Photoshop output equivalence is inferred from native/API agreement.
