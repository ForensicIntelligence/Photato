# Custom Shape Blur

The Shape Blur chooser accepts saved custom shapes from the Shapes panel. Each filter keeps a named vector snapshot with its aspect ratio, so editing or deleting the library preset does not change an existing filter. Selecting a built-in shape clears the custom snapshot. Preview, local Undo/Redo, Cancel, Smart Filter re-edit and document history use the existing filter pipeline. Native preset import is available in the Shapes panel; Adobe CSH import and library loading inside the filter dialog remain open.

The optional API uses `filter.apply` and `smartFilter.set`. For `kind: "shapeBlur"`, `classicDetail.kernel` carries `{name, path}` with native VectorPath components, knots, fill rule and inverted=false. Keys are strict and coordinates finite and bounded. Limits are 4,096 knots, 256 components and 2 MiB settings JSON. Keep the default built-in `shape: "circle"` when supplying a custom kernel. A missing or null kernel retains built-in behavior. Adobe Action descriptors remain unsupported.

Files containing custom kernels require native archive 87; HTTP download requires `X-Photato-Archive-Version: 87`. Portable Actions require version 52. Ordinary detail filters retain native 44 and Actions 17. Preparation and convolution retain the existing work budget of 268,435,456 visits and selected-layer limit of 8,388,608 pixels. These capacity limits remain incomplete requirements. This increment adds no tool, alternate modifier action, factory menu or shortcut.
