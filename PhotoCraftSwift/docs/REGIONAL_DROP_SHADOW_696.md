# Render Drop Shadows in bounded canvas regions

Basic and advanced Drop Shadows now render on large RGB canvases. A viewport prepares the shifted source and the required filter margin.

The basic renderer prepares a shifted alpha window for fractional offsets. The advanced renderer uses rounded offsets and the same tent and spread kernels in the local region. A box with no contributing samples retains exactly zero alpha. This keeps contour anti-aliasing from turning floating-point residuals into visible color outside the shadow. The sparse compositor includes both the layer's original support and its displaced shadow support. [Photoshop effect options](https://helpx.adobe.com/photoshop/desktop/create-manage-layers/apply-layer-effects/layer-style-effects-and-options-overview.html)

Twenty-four RGB8, RGB16 and RGB32 viewport comparisons matched the whole-canvas renderer at tile and document edges. Another 384 varied viewport comparisons matched on each optimized architecture. A sparse 300,000 × 300,000 canvas found a 30,000-pixel displaced shadow and retained under 4 MiB of output tiles in the test. The native menu, advanced controls, preview, Undo, local HTTP edit and PNG were verified on that canvas size. A 4,096 × 4,096 editable PSB reopened with the same effect settings and regional pixels. All 138 prior effect fixtures produced identical direct and imported-project output on both architectures.

A second maximum-size probe used six depth and renderer combinations. All six output crops matched byte for byte across the three builds tested. Every case referenced 512 KiB of mapped output tiles and retained 3 KiB in the tile map. Peak process memory for the whole six-case run was 18.5 MiB on Apple Silicon and 14.0 MiB under Rosetta. [Adobe's published PSB dimensions](https://helpx.adobe.com/ca/photoshop/desktop/save-and-export/export-files-to-different-formats/image-file-formats-supported-in-photoshop.html)

471 of 472 selected tests passed in arm64 Debug, optimized Apple Silicon and Intel under Rosetta. The original PhotoCraft effect fixture reproduced its existing assertions. Both signed macOS 14+ preview slices opened offscreen. The native Layer Style sheet was inspected offscreen in Light and Dark on the maximum-size document. The installed Photoshop instance timed out on a document query. Direct Adobe pixel comparison remains open. Very wide filters retain a scratch budget. A shadow already filling an entire canvas can require additional preview work. Other effects still use their existing whole-canvas limits.
