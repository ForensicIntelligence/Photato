# Source checkpoint 511

8 November 2026, Vancouver. Native Swift 0.3.0/build 511, Source03. Current package: COL02, major-stillneeded. Merge Channels remains in progress; COL03 follows it. No major scope or command requirement is closed by this checkpoint.

While testing source documents for Merge Channels, Photoshop 2026 rejected Gray32 PSDs produced by Photato. Photato could read its own files, so the existing round-trip tests did not detect the interoperability defect. A Gray32 document saved by Photoshop contained a 110-byte HDR toning block in its color-mode data; Photato wrote that block only for RGB32. The shared writer now includes it for Gray32 as well, preserving an imported block or using the existing neutral default. That default retains its licensed Rust-source attribution. No Adobe implementation code or SDK was inspected or copied.

`Sources/PhotoCraftImaging/PSDCodec.swift` contains the production repair. `scripts/Info.plist` increments build 510 to 511. `Sources/PhotoCraft/AutomationDocumentTransfers.swift` advertises the metadata behavior. Existing native Save/Save As/Save a Copy, Photato PSD/PSB downloads and both resource job serializers use this shared codec. No new endpoint or typed command was added: the count remains 269. Native format 92 and Actions format 60 are unchanged. Factory menus, shortcuts, cursors, entitlements and the Xcode project are unchanged; the project remains included.

Added `PSDGray32MetadataTests.swift`, `Gray32ExportWorkflowTests.swift`, and an owned procedural Photoshop Gray32 fixture with provenance under `Tests/PhotoCraftImagingTests/Fixtures/gray32`. Tests cover every supported compression in PSD and PSB, file/Data output equality, all native component words, retained imported toning data, lower-depth Gray and RGB32 regression behavior, real authenticated HTTP downloads with denied/stale requests and unchanged source state, and the resource-output serializer in both API configurations. The resource test exercises their common encoder; it is not an end-to-end hosted Adobe service test.

Before the repair, Source02 ran three new imaging methods: one passed and two failed with 18 assertions because the expected block was absent. No methods were skipped and no signal occurred. After the repair, the same 7,752 Source03 inputs pass all 32 selected methods in Debug, optimized Apple Silicon and optimized Intel under translation. All five new methods pass in each configuration, with no missing, duplicate, extra or skipped methods and no test signals. Exact commands, full input hashes and separate failed/passing logs remain in the local `511-merge-channels` run. The public snapshot binds the receipts by hash.

Actual Photoshop opens all eight exported Gray32 files: PSD and PSB with raw, RLE, ZIP and predicted ZIP compression. The raw PSD was saved to a separate owned file. One UI check initially looked for a properties popup not exposed in this context; the window title already showed a successful Gray32 open. A transient automation pipe failure occurred after closing the RLE PSB; a fresh read of the same running Photoshop session confirmed closure. No app was restarted or force-quit. All owned reference and validation documents were closed normally, leaving Photoshop at Home; global preferences were not changed.
