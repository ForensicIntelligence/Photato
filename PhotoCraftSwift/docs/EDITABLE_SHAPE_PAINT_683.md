# Keep shape gradients editable in PSD and PSB

The shape generator now accepts a gradient fill inside `vscg`. Gradient strokes use the editable descriptor nested in `vstk`. The importer reads the existing gradient stops, opacity, interpolation, placement, alignment and dither fields. If Photoshop has invalidated primitive controls, the supported record retains its contour as a custom editable outline.

The first probe on build 682 rejected the original gradient rectangle. Build 683 opens it directly. Two other full documents still fail because of unrepresented pattern paint or effects. Local derivatives retained the original gradient shape descriptors while removing unrelated layers or transplanting one descriptor. The fixture files and derivatives were kept local. [Gradient rectangle](https://github.com/psd-tools/psd-tools/blob/6a827c19543106cd83a50fd830b07312df950531/tests/psd_files/effects/inner-stroke-transparent-gradient.psd) · [Gradient outlines](https://github.com/psd-tools/psd-tools/blob/6a827c19543106cd83a50fd830b07312df950531/tests/psd_files/effects/stroke-effects.psd) · [Gradient stroke](https://github.com/psd-tools/psd-tools/blob/6a827c19543106cd83a50fd830b07312df950531/tests/psd_files/stroke.psd)

An independent reader compared eight layer/file pairs. Their live descriptors and complete RGBA layer caches matched byte for byte. The original Photoshop gradient rectangle supplied two pairs. Four came from two gradient outlines isolated from a separate Photoshop file, and two came from a rectangle carrying a Photoshop-authored gradient stroke descriptor transplanted from a live line. Photato reversed the gradient on each shape, saved and reopened the edited files, and undid the edit. The six edited files matched byte for byte across all three builds.

All 300 selected tests passed in Apple Silicon Debug, optimized Apple Silicon, and optimized Intel under Rosetta. Both slices of the signed macOS 14+ preview launched offscreen. Twelve prior vector exports, thirteen prior shape specimens and three canvas-cutout exports also retained identical bytes. The API regression uploads an editable PSD, changes both paints and compares the PSD and PSB downloads with the native encoder.

The original file containing patterned shape paint and the original file containing unsupported pattern layer effects still reject. The derivative fixtures isolate shape metadata and leave pattern paint, line controls, seeded dither and whole-file compatibility open. An equivalent-angle native repaint differed in alpha by up to three 8-bit levels throughout a 32 × 32 interior sample. Its RGB values matched. A separate diagnostic shifted the gradient center by half a pixel and matched all 1,024 alpha samples in that window. Reopening the new files in a live Photoshop 2026 session remains unverified.
