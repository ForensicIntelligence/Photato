# Print Selected Area on large documents

19 November 2026 · Development preview 635

**File > Print > Print Selected Area** can now print a bounded region of a sparse 300,000 × 300,000-pixel document. Make a selection before opening Print, then turn on Print Selected Area. An oversized full-image print shows an inline message and leaves the checkbox under the user's control. The PDF and print preview use the rectangular bounds at the document's print resolution. The source document and editing history stay intact. [Adobe Print Selected Area](https://helpx.adobe.com/photoshop/desktop/print/print-images-from-photoshop.html)

The print layout checks the output region against the 8,388,608-pixel limit. For regional renders, the compositor receives the source-space rectangle. Flat retained channels and Multichannel inks sample the rectangle directly. Eligible layered CMYK separations keep the original layer offsets and compose the retained process numbers for the rectangle only. Duotone reuses the same tone-curve quantizer when writing print pages and converting the whole document to Multichannel. The API advertises the scope of the pixel limit and uses committed print settings for PDF output. The existing API heap and transfer budgets apply. [Photato API](AUTOMATION_API.md#print-selected-area-checkpoint-635)

An independent fixture cropped the far 24 × 16 corner of an owned 300,000 × 300,000 CMYK stack containing an opaque base, a translucent layer and a saved spot. An integer reference matched all 1,920 samples across the five prepared plates, and a separate parser recovered those exact 16-bit words from the PDF streams. Poppler identified all five named pages and rendered their layout and registration marks.

The final Apple Silicon Debug run passed all 45 focused cases in 26.56 seconds, including exact RGB samples under a feathered selection, translated CMYK layers, and the native preview and authenticated PDF route. Earlier test attempts exposed invalid fixture metadata and test coverage outside the intended rectangle. Both test fixtures were corrected before the final run. The signed Apple Silicon preview passed signature verification after ZIP extraction and produced a 1,000 × 650 offscreen workspace snapshot. All 1,166 selected tests passed in Apple Silicon Debug, optimized Apple Silicon and Intel under Rosetta. Both slices of the extracted macOS 14+ universal archive passed signature and offscreen launch checks.

The [source patch](../artifacts/635-print-selection/print-selection-source.patch) applies cleanly to the previous frozen source and reverses cleanly from this build. The [test log](../artifacts/635-print-selection/focused-print03.log) and [PDF sample check](../artifacts/635-print-selection/independent-pdf-streams01.json) accompany it.

The full-image preparation limit, dense documents beyond the API's resource bounds, complex CMYK stacks and physical printer checks remain open. Neighborhood adjustments and some rich layer preparation can still require larger intermediate renders. This measurement used Photato fixtures and Adobe's published workflow. A byte comparison with Photoshop print output remains open.
